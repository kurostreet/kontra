# KONTRA SITE v16 — EXIT + COMPACT MENU

Статический сайт для Cloudflare Pages или GitHub Pages.

## Что добавлено

- победная лунка `EXIT` перенесена из верхней зоны старта в нижнюю часть игрового поля, поэтому шар больше не выигрывает сразу после вылета из трубы;
- во всех видимых местах и favicon используется присланный логотип с бойцом в противогазе;
- в выдвижном меню отображается выбранный публичный аватар игрока;
- меню собрано в компактные группы: аккаунт, сообщества, полезные ссылки, скачивание и IP сервера;
- Telegram подписан как неофициальная группа, Discord — как официальная;
- добавлена «Связь с администрацией» на `https://t.me/blackmodru`;
- «Привилегии» полностью удалены;
- копирование IP работает через системный Clipboard API и резервный способ для мобильных браузеров;
- пусковой канал пинбола полностью освобождён от мишеней, рельсов и зон слива;
- до выхода через верхние ворота шар защищён от коллизий игрового поля, поэтому запуск больше не заканчивается мгновенным поражением;
- в выдвижное меню добавлен официальный сайт разработчика `https://kontramobile.com/#/`;
- активный раздел нижней навигации выделяется анимированной красно-синей электрической обводкой;
- полноценный неоновый пинбол с физикой шара, лапками, пусковым каналом, бамперами и нижними сливами;
- 3 бесплатные попытки в сутки для зарегистрированного игрока, сброс в `00:00 МСК`;
- мишени на `1`, `5` и `10` токенов;
- маленькая зелёная мишень даёт `+1 попытку` один раз за игру;
- победная лунка `EXIT` завершает игру победой и даёт джекпот `25 токенов`;
- нижний центральный или боковой слив завершает попытку поражением;
- покупка одной попытки за `100 токенов`;
- максимальная серверная награда за одну игру — `75 токенов`;
- отдельные разделы «Правила» и «Награды» на русском и английском;
- попытки, активные игры, покупки и результаты сохраняются в D1;
- повторная отправка результата не может начислить награду второй раз;
- токены сайта синхронизируются с LVL MOD накопительной ревизией и применяются ровно один раз;
- прежние функции v13 сохранены: аватары, TOP с коронами, ссылки App Store / Google Play, дневная и ночная темы, WEB CONTROL.

## Публикация сайта

Загружайте **содержимое папки сайта прямо в корень репозитория**. В корне должны лежать:

- `index.html`;
- `app.js`;
- `styles.css`;
- `config.js`;
- папка `assets/`.

Для Cloudflare Pages: Framework preset `None`, build command `exit 0`, output directory `/`.

## Обязательное обновление сервера

Для постоянных попыток и настоящего начисления токенов установите:

1. `server/LVL_MOD_v71_PINBALL.lua` вместо текущего LVL MOD;
2. `worker/KONTRA_WORKER_v3_9_PINBALL_D1.js` вместо текущего Cloudflare Worker;
3. файлы сайта v16.

Отдельная D1-миграция не нужна: Worker сам создаёт таблицы пинбола. После Deploy откройте `/health` у Worker — в ответе должны быть:

- `"apiVersion": 3.9` на корневом адресе;
- `"pinballSchema": true` на `/health`;
- адреса `/pinball`, `/pinball/start`, `/pinball/finish`, `/pinball/buy`.

Если сайт v16 открыть со старым Worker v3.8, пинбол автоматически включит безопасный режим проверки. Играть и проверять интерфейс можно, но результат будет храниться только на этом устройстве и не попадёт в настоящий баланс до установки Worker v3.9 и LVL MOD v71.

Основные адреса API задаются в `config.js`.
